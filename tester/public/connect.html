Connect your own agent

Give an agent you already use this address. It can then put your meetings, asks and to-dos on your Meridian, and show what it’s working on in the strip along the bottom, live.

…
  1. In a terminal: codex mcp add meridian-test --url …
  2. Start a Codex task as normal, and add: “As you work, keep my Meridian up to date with agent_status.”
  3. Watch the strip at the bottom of Meridian. To take it off again: codex mcp remove meridian-test
  1. This needs ChatGPT Plus or Pro with developer mode on (Settings → Apps → Advanced). Work accounts often block it; if yours does, use “Copy a prompt for ChatGPT” above instead.
  2. Go to chatgpt.com/plugins, press +, then Add custom MCP server. Name it Meridian test, paste the address, choose No authentication, and create it.
  3. In a chat, try: “@Meridian test put today’s meetings from my Outlook calendar on my Meridian.”
  1. In Claude: Settings → Connectors → Add custom connector, and paste the address.
  2. Or in Claude Code: claude mcp add --transport http meridian-test …
  3. Then ask it to keep your Meridian up to date as it works.

The address only opens your test copy. Anyone with it can add things to it, so keep it to yourself.

Add your calendar link

A published calendar link (.ics) brings in your next week of meetings. In Outlook on the web: Settings → Calendar → Shared calendars → Publish a calendar, then copy the ICS link. In Google Calendar: your calendar’s settings → Secret address in iCal format. Many work accounts turn publishing off; if yours has, skip this.
