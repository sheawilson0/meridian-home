# Planet textures

Ten Solar System Scope / INOVE source textures, used under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), were resized to 1024 px wide and converted to WebP at quality 82. Surface maps are 1024×512; Saturn’s ring is 1024×62 and preserves alpha. No seam retouching or colour changes were applied.

[Original source downloads](https://www.solarsystemscope.com/textures/), [complete attribution](../../../THIRD_PARTY_NOTICES.md).

This public snapshot ships only the WebP derivatives. The dashboard and settings previews share their loader and do not request excluded JPEG/PNG originals. Recover the upstream 2K originals separately before regenerating derivatives with your chosen image tools.
